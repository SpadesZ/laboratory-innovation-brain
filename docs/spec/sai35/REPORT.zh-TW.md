## 0. candidate.2 修正了什麼

編號不變。77 條需求、12 項能力、架構都不變。只修四個語意錯誤，加一個稽核。

- **S1 機制可區分性（S35-MECH-001）。** 舊版把「兩兩分不開」當成等價關係，這是錯的。
  反例：A = 0、B = 0.75、C = 1.50，門檻 1。A/B 分不開，B/C 分不開，但 A/C 分得開。
  舊版的遞移合併會得到 1 類；單純計數會得到 3；正確答案是 2。
  新定義在 [附錄 S](mechanism-distinguishability.md)：
  - 機制身分 = 正規化前向模型的雜湊，與名稱無關。同身分 = 別名。
  - 每一對只有三種判定：可區分、不可區分、未判定（UNRESOLVED）。用參數範圍的最壞情況。
  - 多樣性 = 兩兩「經認證可區分」的最大集合大小。報下界；有未判定時也報上界。
  - 改名、近似複製、遞移合併都不能改變這個數。
  - 新增「目錄充分性」：所有候選機制都不夠好時，不能硬套最接近的那個。只能放棄、擴充、
    重新框定、要求鑑別實驗或停止。預算變大也不能放寬標準。
- **S2 匹配成本比較（S35-CMP-002、附錄 J §3）。** 舊版在執行後才用「各組最小的最終花費」
  當比較點，這會被結果影響。新版：
  - 實際成本檢查點在任何一組開跑前就凍結。
  - 每次嘗試（模型呼叫、重試、失敗、實驗）在開始時就計入全部成本。
  - 跨越檢查點的實驗不能提供該檢查點的證據。
  - 每組的分數只看自己的紀錄，所以提早停止不能移動比較點。
  - 紀錄不完整或對不上時標為 COST_UNMATCHED。舊規則只能當次要敏感度分析。
- **S3 知識階段的範圍（S35-HYP-001）。** 三個知識階段只用在假說和科學主張。
  問題、觀測、異常、實驗、登記、物理模型等紀錄，保留自己的格式和狀態機。
- **S4 探索、預算與安全停止。** 新增授權階梯（[附錄 E §9](governance-security.md)）：
  花錢的授權 ≠ 假說准入 ≠ 證據支持 ≠ 獨立因果確認。有授權的探索性模型呼叫，產出仍只是想法，
  不是證據。新增三個終止維度（[附錄 A §3.1](lifecycle.md)）：作業性終止、實驗完成度、科學接受。
  在任何實驗前安全停止 = 有效終止，但不是完成的實驗，也絕不是發現。OD-14 保守預設不變。
- **S5 一致性稽核。** 77 條逐條檢查，結果在 [附錄 T](semantic-consistency-report.md)。
  21 條修正或澄清。另外修了 S35-PROB-001（成員接受問題不等於可以花錢）和
  S35-MOD-003（「exploratory run」不是知識階段）。
- 數學定義和反例寫成可執行檔 [semantic_reference.py](semantic_reference.py)。檢查器每次都跑它。
  它也確認 6 個已知錯誤的定義（例如遞移合併、事後挑比較點）全部被拒絕。
- 新的 Owner 決定：OD-17（可區分性門檻與界限方法）、OD-18（目錄充分性標準與放棄政策）。
- 新的 spec issues：S35-ISSUE-11～15。

## 1. 改了什麼

- 新的主規格：[SAI_3.5.md](../SAI_3.5.md)。它是唯一入口。
  - 寫明效力順序：SAI 3.3、SAI 3.4 的義務全部保留。啟用前，衝突時以它們為準。
  - 衝突一律記成 spec issue，並停止受影響的工作。不採「新版優先」。
  - 有導覽表，列出每份附錄，以及它是規範性還是參考性。
- 產品目標：矽光子的自主 AI 科學家。這是目標，不是現況。
  - 共 12 項能力：發現問題與異常、提出新穎且可否證的假說、擴大機制搜尋空間、
    研究重新框定、獨立評估競爭解釋並選鑑別性實驗、從零建模、
    由內部 worker 執行有授權的 Lumerical、掃描／收斂／不確定度／細化／獨立物理驗證、
    發現與驗證的回饋迴圈、雙語可重現報告、不靠外部 coding agent 的完整流程、治理與安全。
  - 它不是文獻摘要器、聊天機器人、模擬啟動器，也不是假說審查助手。
- 77 條需求，編號 `S35-<領域>-NNN`。不會和 SAI 3.4 的 `D-01`–`D-08` 混淆。
  每條都有驗收測試、負責元件、階段、關卡、狀態與繼承關係。
- 三個知識階段：探索性想法 → 可檢驗假說 → 有證據支持的結論。
  Discovery 只能提出，不能確認。只有 Causal Warrant Gate 能給 CONFIRMED。
- 研究授權範圍（ResearchEnvelope）：在 Owner 核准的範圍內，系統可以自動做前瞻登記。
  但它不能授權結論。實體實驗、製作、發表永遠要逐次核准。
- 自主等級 AL0–AL4。沒有授權範圍時，預設只能提出建議（AL1）。
- A/B/C 比較：(A) 單一前沿 LLM、(B) 現有 LIB、(C) LIB 加 Discovery。
  比的是**實際消耗**相同時的表現，不只是預算上限相同。
  五個指標：真因發現、有效機制多樣性、鑑別實驗效率、錯誤發現、獨立可重現性。
  隱藏世界由獨立評估者產生。實作者寫的合成世界不算 G-D 證據。
- 附錄：生命週期、架構與責任、紀錄與狀態機、溯源與新穎性、治理與安全、
  介面與雙語詞彙表、部署與自主性驗收、路線圖、G-D 驗收、比較協定、
  對照矩陣、實作現況、相容性分析、啟用提案、Owner 決定、spec issues。
- 舊的候選檔 [SAI_3.5_Discovery_Candidate.md](../SAI_3.5_Discovery_Candidate.md) 保留，加上「已被取代」的說明。
- 新增 ADR-0017。ADR-0016 標為部分被取代。
